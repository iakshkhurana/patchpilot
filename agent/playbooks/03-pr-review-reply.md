# Playbook 03 — PR review reply

## When to use it

A maintainer left review comments on my PR. I want every point answered in one pass instead of trickling replies and forgetting one.

## Prompt to send

```
reply https://github.com/cataclysmbn/Cataclysm-BN/pull/<number>
```

## Expected output

1. Reviewer points — one bullet each, with handle and file/line.
2. Draft reply in first person, same order as the points. Each point gets an answer or a concrete "I'll change X". Spots that need my judgment show up as `[your call: ...]`.

No AI mentions, no flattery. Under 500 words.

## What I do with it

Read every `[your call: ...]`, decide, rewrite in my own words where it sounds off, then post it myself. The draft is a starting point, not the message.
