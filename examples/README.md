# examples/

Sanitized copies of real PatchPilot outputs, one file per run. Naming: `NN-command.md`, e.g. `01-triage.md`, `02-repro-10447.md`.

Each file starts with a 3-line header:

```
date: YYYY-MM-DD
command: triage cataclysmbn/Cataclysm-BN
screenshot: evidence/<file>.png
```

then the raw output exactly as the agent returned it. Nothing here is written by hand.
